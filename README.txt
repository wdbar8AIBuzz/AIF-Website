AI in Finance (AIF) — University of Minnesota
Redesigned site
=============================================

HOW TO VIEW
-----------
1. Unzip this folder, keeping all files together.
2. Double-click index.html — it opens in your browser.
3. Fonts load from the internet, so view it while connected.

WHAT'S NEW IN THIS REDESIGN
---------------------------
- Live "rewriting" headline on the home page: AI is rewriting
  finance. / markets. / investing. / research. / careers. —
  typed and retyped with a gold caret. Edit the word list at
  the top of script.js.
- Stock-ticker strip under the hero (pauses on hover).
- New type system: Instrument Serif (headlines), Instrument Sans
  (body), IBM Plex Mono (labels, ticker, data).
- Ledger-style rows for the Experience section and Events page.
- Leadership grid: photos start black & white and bloom to full
  color on hover.
- Same maroon/gold brand, same pages, same photos and logo —
  drop-in replacement for the old folder.
- Respects "reduce motion" accessibility settings.
